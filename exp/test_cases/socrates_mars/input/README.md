# Socrates Mars spectral files

`socrates_mars_test_case.py` requires the following Mars-specific Socrates spectral files to
be placed in this folder before it can be run:

* `sp_lw_17_dsa_mars`
* `sp_lw_17_dsa_mars_k`
* `sp_sw_42_dsa_mars_sun`
* `sp_sw_42_dsa_mars_sun_k`

These can be found through the ROCKE-3D website.

The test case can also be run with MOLA topography, which is currently commented out in the test case.
